File Probe read-only

Asks the pedal whether it answers Zoom's file commands as the ZD2 pedals do (from zoom-zt2). This page only sends the commands listed below: identity, editor mode, disk usage, list files, close the listing. It never opens, writes or deletes a file. Close Zoom Effect Manager first (it holds the MIDI port), and use Chrome or Edge.

Not connected
Only if steps 2 and 3 get no answer.
